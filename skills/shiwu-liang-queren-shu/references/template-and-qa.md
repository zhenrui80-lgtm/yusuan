# 模板保留与成品检查

## 编辑前

1. 记录源文件与模板路径、哈希或等价版本指纹。打开并阅读真实模板；不要仅依据用户截图重建表格。
2. 旧 `.doc` 或 `.xls` 如需转换，使用可用的 Word/Excel/WPS/LibreOffice 另存副本；比较转换前后页面、合并单元格、字体和签字区域。扩展名重命名不等于格式转换。
3. 确认本机文档、表格、PDF 库及渲染工具。在 Codex 桌面环境可先读取工作区依赖路径；不要假定某个 Python 库、Office COM 或渲染程序一定已安装。相关文档/表格技能可用时按其文件操作要求执行。
4. 仅保留本项目需要的模板结构，不带入旧项目名称、地点、合同、日期、材料量、价格、人员或签章。保留用户提供原件，签字栏由实际签认人员填写。

## Word 确认书

优先编辑原模板段落/run和单元格内容，保留表格网格、宽度、边框、字体、字号、段落间距、对齐、页边距、页眉页脚、确认栏及签字栏。替换整段文本可能丢失 run 格式；重建表格可能丢失单元格边距和跨页行为，应避免。

- 左栏措辞对照原模板逐条优化，不堆砌清单全部项目特征，也不压缩到失去施工范围。保留关键材质、厚度、型号及拆装/运输/恢复工序。
- 右栏每条材料的名称、规格、数量形成同一阅读单元，不能把数量甩到下一页而名称留在上一页。
- 一行材料过多时，可使用模板允许的续行或续页；标明属于同一工程项，工程量只计一次。禁止对超过一页高度的整行强制“不拆分”造成溢出。
- 重复表头需用真实表头属性；页末说明和签字栏不能消失。末尾空段落造成额外空白页时只处理多余空段落，不删除签字内容。
- 依据、假设及待核事项写入批注或底稿。材料正文可使用“测算量”“甲方实发量”等准确标签；不要正文已改为甲方量，批注还保留旧损耗计算。
- 输出解除继承的编辑限制，保持可编辑；不伪造签章，不把扫描签名搬到新表。

## Excel 材料台账

保留既有工作表、列序、表头、合并单元格、行列尺寸、字体、边框、数字格式及原有公式结构。扩展明细时复制对应样式行，并更新必要公式、打印范围，避免插行后公式错位。

- 数量为真实数值，单位单独写入模板指定位置；窄数量栏不要填“12.345 kg”字符串。名称和规格分别放在模板对应字段。
- 明确“确认书采用量”和“入库、出库、结余”关系。测算模式在用户要求时使入出同量；实际模式按实际收发，不为与确认书表面相等而抹平库存。
- 库存采用模板公式；本期结余通常为期初＋入库－出库，不能对含期初的台账机械只算入－出。实际结构以模板为准。
- 日期、确认人、签字按用户决定及凭证填写。不存在的日期保持真正空单元格，不填 0 或系统当天。
- 数量为空时避免显示为 0，未知分项不能被 `SUM` 的跳空行为隐藏成“完整总计”。
- 清除旧项目明细值及批注，保留必要空白样式；不要让尾部历史材料进入打印区或汇总公式。
- 重算并检查公式结果/缓存，无 `#REF!`、`#VALUE!`、`#DIV/0!` 等错误；不能仅以公式字符串存在判定正确。
- 按模板纸型、方向、重复标题行和分页规则输出；可在不改变表格样式前提下调整打印范围，不能缩成不可读的小字来塞一页。
- 交付工作簿、工作表不设密码或保护。

## 从保存的文件读取真实内容

为每个工程项、确认书右栏材料和台账分组建立独立提取结果。DOCX 可读取 OOXML/文档库，Excel 可用电子表格库读取值、公式和批注；读取源必须是最终保存的文件路径。无需把内部 ID 印进模板，可用底稿的表/行位置映射。

检查数量时同时检查名称、规格、单位；不同材料凑出同样总数不算通过。每条明细恰好匹配一次，续行工程量不能重复；同规格在台账应按实际汇总口径合并，保留 contribution 列表在底稿中。

通用 `reconcile.py` 检查规范化数据，不直接解析任意 Word/Excel 模板。调用方必须独立提取回读 JSON，工具不会替代范围识别、来源证据审核或版式检查。只跑模型检查而未传 `--readback` 时，不能宣称已完成最终两表验收。

## 渲染与验收记录

导出 Word 和 Excel 的 PDF/页面图；逐页检查整页，再检查字号较小和长规格部位。关注表格越界、字被裁切、行高不足、数量断页、重复工程量、分页多余空白、签字页和 Excel 单位溢出。

用 Office COM 自动化时，新建自己拥有的隐藏实例，操作副本并在 finally 释放；不要关闭用户已有的 Word/Excel/WPS 窗口。没有 Office 时使用可用替代渲染器，记录兼容性限制；不要因导出命令返回成功就忽略页面图。

底稿验收记录应指明：输入及输出版本、逐项数量/规格检查、重复及未知项、甲方来源使用情况、公式结果、模板结构比较、逐页视觉检查、未完成项。修改影响数量、规格、分组或分页后重跑相应检查。最终只交付用户请求的成果，简述待核事实；日志和测试图留在工作底稿。
